- 负责文件：`index.html`、`styles.css`
- 完成日期：2026-10-20
- 关联问题：验收报告 `59e45aa` 中的 S2（手机端弹窗操作区）与 C3（权限矩阵窄屏提示）

## 工作内容

本轮只处理验收报告中列为“应该改”的 S2 与“可以改”的 C3。修复未改动 `app.js`、后端服务与公共测试脚本，分支基于最新 `main` 创建，未合并主干、未删除既有分支。

手机端弹窗的问题由两处叠加造成：页面级断点把所有 `.section-heading` 改为纵向排列，弹窗标题行被一并拉伸，关闭按钮占满整行；操作区位于表单末尾，390×844 下排在弹窗可视区之外。修复方式是在断点内单独把弹窗标题行恢复为横向排列，并把错误提示与操作按钮收进 `.dialog-footer`，用粘性定位吸附在弹窗底部，弹窗滚动时底栏保持可见。弹窗同时增加底部滚动内边距，键盘焦点移到靠下字段时不会被底栏遮挡。

权限矩阵保留原表格，不改为卡片布局。窄屏在表格上方增加固定提示，右侧增加渐隐遮罩，表格容器设为可聚焦区域并补充用途描述，键盘用户聚焦后可用方向键横向滚动到“保存权限”。桌面宽度不显示提示，表格完整展示。

## 修改点

| 位置 | 修改 | 目的 |
| --- | --- | --- |
| `index.html` 两个弹窗 | 错误提示与 `.dialog-actions` 收进 `.dialog-footer` | 为底栏吸底提供结构 |
| `index.html` 权限矩阵 | 外层 `.table-scroll`，容器加 `tabindex="0"`、`role="region"`、`aria-label`，上方加 `.scroll-hint` | 提示右侧仍有列，并支持键盘滚动 |
| `styles.css` 弹窗 | `.dialog-footer` 粘性定位、`scroll-padding-bottom` | 保存、刷新常驻可见，焦点不被遮挡 |
| `styles.css` 断点 | `dialog .section-heading` 恢复横向，关闭按钮固定宽度 | 关闭按钮不再拉伸为整行 |
| `styles.css` 矩阵 | `.scroll-hint` 与 `.table-scroll::after` 渐隐仅在窄屏显示 | 给出可滚动线索，不影响桌面布局 |
