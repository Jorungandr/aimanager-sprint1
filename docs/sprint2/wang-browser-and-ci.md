## 工作内容

本轮新增真实 Chromium 浏览器验收。脚本在临时数据库中初始化管理员、只读成员、项目、需求和任务，逐项验证只读成员只能查看项目，创建需求、创建任务、编辑任务和变更状态的请求均被服务器以 403 拒绝；管理员移出该成员后，成员刷新页面不再看到项目，直接请求项目任务也继续被拒绝。脚本还检查无结果筛选的“清除筛选”、任务卡键盘变更状态，以及 390×844 移动视口中的横向溢出与主要控件 44×44 CSS 像素尺寸。

CI 保留两组独立回归：`backend-regression` 执行 Python 单元和 HTTP 集成测试，`browser-regression` 安装锁定版本的 Playwright 与 Chromium 并执行浏览器验收。工作流中的 `actions/checkout`、`actions/setup-python` 和 `actions/setup-node` 均更新为 v7，避免继续使用存在弃用提示的旧运行时。
