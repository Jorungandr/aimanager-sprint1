# 爱管理用户手册（v1.0.0）

本手册面向首次运行与验收演示的人员，覆盖安装、初始化、日常操作、数据概览与常见问题。产品是课程教学原型，只监听本机地址，请使用虚构邮箱与口令，不要输入真实凭证。

## 一、准备与启动

1. 安装 Python 3.11 或更高版本。服务端只使用标准库，无需安装第三方包。
2. 在项目目录执行 `python server.py`，终端显示 `打开 http://127.0.0.1:8765` 即启动成功。
3. 浏览器访问 `http://127.0.0.1:8765`。数据保存在 `data/aimanager.db`，删除该文件会清空演示数据。
4. 如需执行浏览器回归，另需 Node.js 与 Playwright：`npm ci`、`npx playwright install chromium`、`npm run test:browser`。

## 二、首次使用

1. 首次打开显示“初始化管理员”，填写邮箱与 8—128 位口令，点击“创建并登录”。该账号是平台管理员，拥有全部权限。
2. 进入“管理配置”，先创建角色（如“项目经理”“成员”“只读成员”），在角色—权限矩阵中勾选权限并点“保存权限”。含管理类权限的角色会自动包含“查看项目”。
3. 创建演示账号，再创建项目。创建者自动成为该项目的项目内管理者。
4. 在“项目协作”中展开“项目成员”，选择账号与可授权角色，点击“加入并指派角色”。

权限共五项：查看项目、管理成员、管理项目、管理角色、管理需求任务。界面会隐藏无权操作的入口，但真正的判断全部在服务器端执行。

## 三、需求与任务

1. 展开“新建需求或任务”，先保存需求（标题 1—80 字，说明最多 500 字），再创建任务并关联需求；也可以选择“不关联”。
2. 任务可指派当前项目成员、设置截止日（`YYYY-MM-DD`），状态为待梳理、待办、进行中、已完成。
3. 看板支持拖拽换列，也可用卡片内的状态下拉框完成同样的操作，键盘用户使用后者。
4. 卡片右上显示负责人与截止日；未完成且已过截止日会标注“已逾期”。
5. 需求支持编辑、归档与恢复。归档后不出现在新任务的关联选项里，历史任务的关联保留并标注“已归档”；恢复后可继续关联。
6. 保存冲突：若他人已修改同一条目，页面提示版本冲突并保留当前输入，点击“刷新数据”后重新编辑，不覆盖他人修改。

## 四、数据概览

“数据概览”跟随顶部“当前项目”，只统计该项目的数据。

1. **健康度卡片**：任务总数、已完成（含完成率）、已逾期、3 天内到期。除总数外均可点击下钻。
2. **状态分布**：四列柱形，高度表示任务数；点击柱形或按回车查看该状态的任务明细。
3. **完成趋势**：最近 14 天累计完成数，按任务首次进入“已完成”的日期累计；点击数据点查看当天完成的任务。
4. **负责人分布**：横条长度为任务数，深色段为已完成；点击查看该负责人的任务。
5. **需求完成率**：只统计已挂接任务的需求，含“未关联需求”分组；点击“下钻”查看明细。
6. **逾期与风险任务**：未完成且已逾期或 3 天内到期的任务，按截止日升序。
7. **变更记录**：任务、需求与成员角色的变更，可按对象类型筛选；显示时间、操作人、对象与字段前后值。

数字口径：逾期按“未完成且截止日早于今天”；趋势末点与“已完成”数一致；历史完成但没有事件记录的任务计入趋势起点。

## 五、权限与安全

- 只读成员（仅“查看项目”）可以查看看板、需求与数据概览，但不能新建、编辑、拖动任务或管理成员。
- 成员管理者只能指派不超过自己在当前项目权限的角色，也不能修改或移除权限更高的成员。
- 会话保存在服务器进程内，约 2 小时后或服务重启后需要重新登录。
- 所有写请求需要 CSRF 令牌；页面已自动处理，外部脚本须先请求 `GET /api/csrf`。
- 服务仅监听 `127.0.0.1`，不提供 TLS，不要改为对外开放地址。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 页面提示“登录已过期” | 重新登录；未保存的编辑会被关闭，请先复制内容 |
| 保存时提示版本冲突（409/428） | 点击弹窗内“刷新数据”，重新打开条目后再改 |
| 看不到“管理配置” | 当前账号没有角色或项目管理权限，请联系管理员 |
| 数据概览为空 | 当前项目还没有任务；先创建任务或切换项目 |
| 数据库版本报错（409） | 程序与数据库版本不匹配，使用匹配版本的程序或数据库副本 |
| 浏览器回归启动失败 | 设置 `PYTHON` 为解释器路径，并为 127.0.0.1 配置 `NO_PROXY` |

## 七、停止与备份

停止服务使用 `Ctrl+C`。备份时先停止服务，再复制 `data/aimanager.db`；不要用旧版本程序打开新版本数据库。升级到 v3 结构时，含用户数据的 v2 数据库会自动生成 `.pre-audit.bak` 快照，备份文件含业务数据，不要提交到 Git。
