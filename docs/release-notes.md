# 爱管理 v1.0.0 发布说明（Sprint 3）

发布日期：2026-10-24　　基线：`main`（`v1.0.0` 标签）　　适用环境：本机教学演示（http://127.0.0.1:8765）

## 一、本轮新增

1. **数据概览视图**：新增“数据概览”标签页，展示任务总数、已完成、已逾期、3 天内到期四个指标，状态分布柱状图、负责人分布条图、需求完成率表、14 天完成趋势折线，以及逾期与风险任务清单。
2. **从图表下钻**：点击指标卡、状态柱、负责人条、趋势数据点或需求行的“下钻”，在同一页展示对应任务明细（任务、状态、负责人、截止日）。键盘可用 Tab 聚焦后按回车触发。
3. **统一变更事件**：新增 `audit_events` 表与只读查询接口，记录任务创建与字段变更、需求创建/编辑/归档/恢复、成员加入/改派/移出，含操作人、变更字段与前后值。任务状态事件用于生成真实完成趋势。
4. **角色变更追溯（US-12）**：成员角色被改派时记录原角色与新角色，可在“变更记录”中按对象类型筛选查看。
5. **数据库结构 v3**：旧库启动时自动建表；包含用户数据的 v2 库在升级前生成 `.pre-audit.bak` 快照。

## 三、兼容性与升级

- 接口向前兼容：Sprint 1、Sprint 2 的路径、字段与状态码未改动；新增四个只读 `GET` 入口，均要求 `project.view`。
- 数据库：`PRAGMA user_version` 由 2 升为 3。旧程序不能识别 v3 库，回退时须同时回退程序与数据库副本。
- 事件不影响既有写入语义：任务与需求的版本号、409/428 冲突处理保持不变；事件与业务写入同事务提交，失败一并回滚。

## 四、已知限制

1. 趋势按服务器本地日期分桶，跨时区部署需要统一时区。
2. 事件只记录字段前后值，不保存任务正文快照；历史任务没有事件时计入趋势起点。
3. 下钻单次最多 200 条，超出部分需回到看板筛选。
4. 会话仍保存在进程内，重启后需重新登录；服务仅监听本机，不提供 TLS。
5. 看板卡片排序未提供批量接口，仅记录位置变化事件（TD-S2-02）。
6. 未在 Safari、Firefox 与真实手机设备上执行回归；移动端验证为 390×844 模拟视口。

## 五、验证摘要

- 单元与接口测试：`python -m unittest discover -s tests -v`，共 159 项通过（2026-10-24，122.8 秒）。
- 浏览器回归：`npm run test:browser`，依次执行 smoke、acceptance、interaction、insights 四套脚本；insights 覆盖指标口径、柱形与趋势下钻、键盘操作、只读成员、三档宽度无横向溢出与 44×44 触控目标。
- 持续集成：推送与 PR 触发 `Backend regression`（Ubuntu）、`Backend regression (Windows)` 与 `Browser acceptance` 三个作业，全部通过后方可合入。
