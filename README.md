# 爱管理 Sprint 2 累积增量

本项目以 Sprint 1 的 E01 用户与权限增量为基线，继续实现项目协作链路：创建需求、创建任务、关联需求、指派项目成员、设置截止日，并在“待梳理—待办—进行中—已完成”看板中推进状态。Sprint 1 的邮箱密码登录、角色与权限、项目成员、权限矩阵和权限回收功能继续保留并纳入回归测试。

已对照实验一《项目规划方案》的Sprint 2切片：US-16创建任务及截止日、US-18需求拆解与任务关联、US-19负责人指派、US-22任务状态流转、US-24状态看板；本次补充US-28负责人筛选。这里表示代码功能对应关系，不代替团队现场AC验收。基线中的优先级、留言等其他Should/Could故事不在本次实现范围内。

## 运行

建议使用 Python 3.11 或更高版本（CI使用3.11），服务端使用标准库，无需安装第三方包。浏览器回归需要Node.js与Playwright。在本目录运行：

```text
python server.py
```

浏览器打开 `http://127.0.0.1:8765`。首次打开会显示初始化管理员页面；请自行设置管理员邮箱和密码。数据保存在代码目录中的 `data/aimanager.db`。会话在进程内只保存令牌SHA-256摘要，每个用户最多5个，当前设备重新登录会轮换会话；2小时后或重启后需要重新登录。同一账号与IP在一分钟内失败5次后触发指数退避（1、2、4秒，最高60秒），成功登录清零，过期计数在后续登录时清理。不同账号不会共用失败次数。

## 实现与边界

- 后端：Python 标准库 HTTP 服务、SQLite、PBKDF2 密码散列、随机会话令牌。
- 新账号使用PBKDF2-HMAC-SHA256、600000次迭代和独立16字节随机盐，散列中记录算法与迭代次数。旧版150000次散列仍可验证，仅在成功登录后更新为新格式，错误密码不触发升级；更高的受支持迭代次数不会降级。数据库中异常算法、盐值或超出支持范围的迭代次数会被拒绝，不会直接执行任意高成本计算。
- 权限与完整性：Sprint 1 的四项权限继续保留，Sprint 2 新增项目级 `workitems.manage`；读取需求和任务要求 `project.view`，写入和看板变更要求 `workitems.manage`。任务负责人须为当前项目成员，需求须与任务同属一个项目，截止日采用 `YYYY-MM-DD`，状态只允许 `backlog`、`todo`、`doing`、`done`。
- 服务器执行权限校验，浏览器界面隐藏按钮仅用于辅助提示，不作为安全边界。
- 成员管理者只能指派不超过自己在当前项目权限的角色，也不能修改或移除权限更高的成员。角色维护者修改共享角色时，原有及新权限都必须在其已有授权上限内，不能给自己新增未持有的能力。
- 非管理员的账号选项只包含其管理项目的现有成员和创建者，首次加入新账号由平台管理员操作；角色选项只显示可访问项目中正在使用的角色，平台角色维护者除外。没有可访问项目的普通账号请求角色选项返回403，页面仍能正常显示无项目状态。
- 保存含管理权限的角色时自动包含`project.view`，旧数据库启动时补齐这一依赖。创建者自动成为新项目的项目内管理者，可查看项目、管理成员与需求任务；该身份不授予平台级角色管理权。创建者显示在成员列表并可被指派任务，不能通过普通成员操作移除或覆盖；所有权转移暂不支持。旧项目不猜测创建者，保留平台管理员兜底。
- 更新任务须携带读取时的`version`：缺失返回428、旧版本返回409，成功递增。拖动、状态选择和编辑窗口均遵守该约束。收到冲突时保留当前输入，请关闭弹窗、刷新数据后重新编辑，不自动覆盖别人修改。
- 需求支持编辑、归档与恢复，使用自己的`version`，与任务版本独立；归档保留历史任务关联，禁止新关联，恢复后可重新关联。需求和任务不提供永久删除入口。
- 当前为教学原型，监听本机地址；虽有登录失败限速、线程上限和请求读取超时，但不包含生产部署所需的 TLS、完整流量治理、账号找回、审计日志与跨设备会话持久化。
- 自动测试通过只能证明代码级 DoD 的一部分；团队仍须完成非作者审查、现场 AC 验收、截图/录屏和真实会议签认后，才能把故事标记为正式完成。

## 工作台操作

- 顶部切换项目协作、管理配置、权限验证；只有具备管理能力的账号显示管理配置。
- 右上项目选择器切换当前项目，成员管理、需求列表和新建表单可展开，避免多项目内容堆叠。
- 搜索任务标题或关联需求，按负责人或未指派筛选；列计数为筛选结果，完成进度为当前项目全部任务。
- 任务既可拖动，也可使用状态下拉框；编辑窗口可修改标题、需求关联、负责人、截止日与状态，Esc可关闭。
- 任务逾期按浏览器本地日期提示，已完成任务不标逾期。任务完成率是任务数比例，不是故事点速率或燃尽图。
- 移出项目成员时，在同一事务内清空该项目任务的负责人，保留任务；其他项目的负责人不变。
- 不创建演示默认密码，不覆盖现有数据库。浏览器验证使用隔离的临时数据库。

口令格式兼容提示：本更新不增加数据表，但旧程序不能识别新散列格式，不要让旧分支与本版本交替打开同一数据库。部署前停服保存数据库副本；若需回退，应先保留当前数据，由团队选择匹配的程序和数据库副本，不能直接覆盖升级后的业务数据。开发与自动测试仅操作隔离临时数据库。

脚本接口兼容提示：写请求前先用同一Cookie客户端调用`GET /api/csrf`，保存响应Cookie并取得`csrf_token`，再把该值放入`X-CSRF-Token`请求头。登录、退出或服务器重启后重新获取，不能跨会话移用。令牌端点不写业务数据，不延长登录有效期；HMAC签名密钥仅存于当前进程，重启即轮换。令牌不是访问授权，携带有效令牌的匿名或只读账号仍受401/403权限校验。外部脚本不适配该流程时，写请求会先被拒绝。
