# 爱管理 Sprint 1 用户与权限原型

本项目承接实验一《项目规划方案》的 E01 切片。实现 US-01、US-04、US-05、US-09、US-11、US-13 的最小验证路径：邮箱密码登录、创建角色、配置权限、创建项目、加入或移除成员、查看角色权限矩阵，以及由服务器拦截越权请求。US-13 为 Should，演示时可按容量裁剪。

## 运行

需 Python 3.10 或更高版本，使用标准库，无需安装第三方包。在本目录运行：

```text
python server.py
```

浏览器打开 `http://127.0.0.1:8765`。首次打开会显示初始化管理员页面；请自行设置管理员邮箱和密码。数据保存在运行目录中的 `data/aimanager.db`，会话保存在进程内，重启后需要重新登录。

## 验证

```text
python -m unittest discover -s tests -v
```

演示建议：初始化管理员 → 创建“管理员、项目经理、成员”角色 → 勾选权限 → 查看矩阵 → 创建项目与成员账号 → 把成员加入项目并指派角色 → 使用成员账号登录，调用受保护操作，观察 HTTP 403 → 管理员移除成员，再验证项目访问被拒绝。前端会显示对应失败提示。所有账号和密码都应使用演示数据，不要使用真实凭证。

## 实现与边界

- 后端：Python 标准库 HTTP 服务、SQLite、PBKDF2 密码散列、随机会话令牌。
- 权限：`roles.manage`、`projects.manage`、`members.manage`、`project.view`。管理员初始化账号始终具有全部权限；普通账号通过项目成员关系取得权限，其中任一项目中获授 `roles.manage` 或 `projects.manage` 后可执行对应的平台级管理操作。角色矩阵仅向拥有 `roles.manage` 的账号返回；成员管理者可读取仅含角色名的选项和账号选项，用于指派角色。
- 服务器执行权限校验，浏览器界面隐藏按钮仅用于辅助提示，不作为安全边界。
- 当前为教学原型，监听本机地址，不包含生产部署所需的 TLS、限流、账号找回、审计日志与跨设备会话持久化。
- 实验一的故事级 DoD 还要求团队成员独立审查、PR 与 CI、非作者验收签字和截图。自动测试通过只能证明其中一部分；未经团队现场核验的故事不得标为已完成。当前本地分支的 6 项自动测试已通过，但尚未形成 PR 或 CI 证据。
